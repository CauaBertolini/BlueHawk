O que a API oferece

Usuários

Cadastro, login com JWT e troca de senha.

Coleção

CRUD de boardgames, editoras e da coleção pessoal de cada usuário.

Marketplace

Ofertas de venda de jogos publicadas pelos usuários.

Partidas

Registro de partidas e dos participantes de cada uma.

Rotas protegidas exigem o cabeçalho Authorization: Bearer <token>.
